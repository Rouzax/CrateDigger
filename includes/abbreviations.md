*[NFO]: Sidecar metadata file written next to each video, read by Kodi, Jellyfin and Plex
*[MBID]: MusicBrainz Identifier, the stable ID MusicBrainz assigns to an artist or recording
*[MBIDs]: MusicBrainz Identifiers, the stable IDs MusicBrainz assigns to artists and recordings
*[TTV]: TargetTypeValue, the Matroska tag scope level that decides what a tag applies to
*[B2B]: Back to back, a set performed by two or more DJs together
*[TTL]: Time to live, how long a cached entry stays valid before it is fetched again
